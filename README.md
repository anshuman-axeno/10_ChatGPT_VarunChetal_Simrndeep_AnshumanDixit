A ChatGPT clone built using HTML, SCSS and JS.

Sidebar with new chat, nav items and grouped conversation history (Today, Yesterday, Previous 7 days, Older)
Search bar to filter conversations by title
Delete option on each recent chat
Collapsible sidebar on desktop, slide-in drawer on mobile
Empty state with welcome message and suggestions
Active chat state with user and assistant messages
Auto-growing message composer with attachment, mic and send buttons
Model selector dropdown (Fast, Balanced, Reasoning) - visual only
Mock AI reply after a short delay, picked randomly from predefined responses
Copy, like, dislike and regenerate on assistant replies
Code blocks with separate background styling
Temporary chat toggle
Claim Offer modal with mock pricing plans
Responsive layout for mobile and tablet

All data is static/mock, nothing is fetched from anywhere
AI replies are random, not based on what is typed
Attachments only open the file picker, no real upload/preview
No settings page yet
